# OpenVaultDB publication

This repository publishes the Pubs database manifest and provider descriptor.
The database's public identity is `https://demodb.dev/pubs/`; its public
descriptor is also available from the shared server at
`https://demodb.dev/ovdb/db/pubs/ovdb-database.json`.

The static SQLite, CSV, and JSON exports are available from the DemoDB provider
site. OVDB query access is disabled until a live backend mount has been
verified.
